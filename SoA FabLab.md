Desktops in the fabrications lab use a standard local account and are set to auto-login (kiosk-mode). The endpoints are joined to the CGCENT domain and use certificate-based authentication to join UMiamiWireless using computer account (applied through GPO). All desktops are protected with Deep Freeze.

Local user (Fablab) must be created on the desktop as a standard user. GPO applies local login username and domain once placed on the correct OU. The DefaultPassword registry string value must be added manually to the following registry path:

HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows

These desktops use a local account to keep laser cutter material settings consistent for everyone. Fabrications lab manager may reach out to thaw devices so his staff can update settings when changes take place.
